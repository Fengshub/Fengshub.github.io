# Feng Tian

## Local Development\files\photos\astro

This site uses [al-folio](https://github.com/alshedivat/al-folio) with Jekyll and GitHub Pages.

```powershell
bundle install
bundle exec jekyll serve
```

Open <http://127.0.0.1:4000/> in a browser. After editing, commit and push changes to rebuild the published site:

```powershell
git add .
git commit -m "Update website"
git push
```
